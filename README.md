## 1. サイトの目的と設計方針

**このページの仕事は「今ある内容を、読みやすく、信頼できる見た目で届けること」。** 修正の前に必ず読むこと。

### 文言は現行サイトを一字一句踏襲する（最重要）

依頼者の指示：「コメントや説明文はすべて https://kankyoterrace.jp/ を踏襲」。

| 区分 | 扱い |
|---|---|
| 変えてはいけない | 文章そのもの（語尾・句読点・「~」と「〜」・全角半角）、見出し、見出し下の説明文、会社情報の値、`<title>` と description |
| 揃えてはいけない表記ゆれ | ヘッダー等の「平日9:00~17:00」と、会社概要の「平日9時〜17時」。**どちらも原文なので統一しない** |
| 変えてよい | 改行位置（本文の `<br>` は外してある）、キャッチの区切り方（文節ごとの `<span>`）、強調の見せ方 |
| 原文に無いが足したもの（依頼者に申告済み） | ①ファーストビューの「山口県宇部市｜機械設備メンテナンス・人材教育・福祉用品・安全保護用品」 ②地図と「地図アプリで開く」ボタン ③電話番号を大きく出したお問い合わせボタン ④見出しの英字ラベル（News / Message など） |

**原文に無い文章（新しいキャッチコピー、実績・数字、事業の関係図、インボイス番号など）は、依頼者の了承なしに足さない。** 以前の版にあった「事業間シナジー」の図とインボイス欄は、この方針で削除済み。

### デザイン方針

| 項目 | 決定内容 | 理由 |
|---|---|---|
| 地の色 | 白 `#ffffff` ＋ 青みの淡いグレー `#f2f5f4` | 「クリーン」「環境保全」。瀬戸内の朝霧のイメージ |
| アクセント | 深緑 `#1f6e4e` の**1色のみ** | 作業現場の安全色（緑）から。「安全」と「環境保全」の両方を表す。白地でコントラスト比 6.18 |
| 見出し書体 | Shippori Mincho B1（大きいサイズのみ） | 代表あいさつの誠実な語り口に合わせた落ち着き |
| 本文書体 | Noto Sans JP、16px、行間1.9 | 読みやすさ優先 |
| シグネチャ | PCでは代表の言葉を**縦書き**で固定表示 | 原文だけで作れる、この会社固有の要素 |
| 地域性 | ファーストビュー最上部に「山口県宇部市」、会社概要の横に地図 | 「地域密着」 |
| ダークモード | **作らない**（依頼者の指示で解除済み） | ロゴ・写真が明るい背景前提 |

色を足す、グラデーションを入れる、クリーム色の地にする、といった変更は方針から外れる。

## 2. ファイル構成

```
002_環境テラスHPrenewal/
├── index.html          … ページ本体（1ページ構成）
├── styles.css          … 全スタイル。先頭の :root に色・書体・余白の設定
├── script.js           … メニュー開閉・フェードイン・現在地ナビ・フォームの入力チェック
├── README.md           … この引き継ぎ書
├── images/
│   ├── logo-kt.png         … 使用中のロゴ（450×286、余白なし）
│   ├── logo.png            … 現行サイトの元ロゴ（未使用・保管用）
│   ├── mainImgPc.png       … メイン画像 PC用（1366×768、約1.1MB）
│   ├── mainImgSp.png       … メイン画像 スマホ用（960×1200、約1MB）

└── .claude/launch.json … プレビュー用サーバーの設定（ポート8001）
```

- 全クラスに接頭辞 `kt-` が付いている（SWELLのクラスと衝突しないため）。新しく作るクラスにも付けること。
- 外部ライブラリは不使用。読み込んでいる外部ファイルは Google Fonts だけ。

## 5. よく変更する箇所と変更方法

### 新着情報を追加する

`▼新着情報` の中の `<li>` を1つコピーして、**一番上**に貼り、日付・タイトル・リンク先を書き換える。`datetime` 属性（`2025-12-16` の形）も合わせて直す。

### 電話番号・受付時間を変える

**同じ情報が5か所にある。** 全部直さないと表示がずれる。`0836-38-7833` と `0836387833` で検索すると全部見つかる。

| 場所 | 表示の番号 | `tel:` リンク | 受付時間の表記 |
|---|---|---|---|
| ヘッダー（PC） | 44行目付近 | 41行目付近 | 平日9:00~17:00 |
| ヘッダー（スマホのメニュー内） | 36行目付近 | 35行目付近 | 平日9:00~17:00 |
| 会社概要 | 219行目 | 同じ行 | 平日9時〜17時／土日祝日休み |
| お問い合わせ | 264行目 | 262行目付近 | 平日9:00~17:00 |
| フッター | 319行目 | 同じ行 | 平日9:00~17:00 |

`tel:` の後ろはハイフンなしの番号にする。

### 画像を差し替える

**同じファイル名で `images/` に上書きすれば差し替わる。** HTMLの修正は不要。

| 画像 | ファイル | 比率 | 目安サイズ | 注意 |
|---|---|---|---|---|
| メイン（PC） | `mainImgPc.png` | 16:9 前後 | 横1366px以上 | PCでは縦長に切り抜かれる。見せたいものは画像の右寄りに（`object-position: 72% 50%`） |
| メイン（スマホ） | `mainImgSp.png` | 4:5 | 横960px以上 | |
| 事業画像4点 | `discription_001〜004.jpg` | 3:2（横長） | 横1100px | 人物は中央寄りに。**1枚300KB以下**に圧縮する |
| ロゴ | `logo-kt.png` | — | — | 下の「ロゴについて」参照 |

- 001＝機械設備メンテナンス、002＝人材教育、003＝介護・福祉用品、004＝安全保護用品。
- 画像の比率を変えるときは、`index.html` の `width` / `height` 属性も実寸に合わせて直す（読み込み時に表示がずれないため）。
- 画像を差し替えたら、`index.html` の `alt`（画面読み上げ用の説明文）も内容に合わせて直す。
- JPEGへの変換と縮小（Mac標準の `sips` で可能）：

```bash
sips -s format jpeg -s formatOptions 78 --resampleWidth 1100 元画像.png --out images/discription_001.jpg
```

### ロゴについて

- `logo-kt.png` は、現行ロゴ `logo.png` の「K-TLS」と虹は**そのまま**で、下の社名だけを組み直したもの（「K-TLS」の幅いっぱいに均等配置、ヒラギノ角ゴ W5、濃いめの灰色、上との間隔を確保）。
- 周りの余白を無くしてあるので、ロゴの左端がそのまま「K」の左端になる。
- ヘッダーでの高さ：PC 80px（styles.css の `.kt-header__logo img`）、スマホ 56px。

### ロゴと見出しの左端揃え

ヘッダーのロゴの左端と、ファーストビューの「あしたを、」の書き出しを揃えてある。仕組みは3つ。

1. ヘッダーの左右余白（`.kt-header__inner`）と、ファーストビュー本文の左余白（`.kt-hero__body`）が同じ計算式 `max(var(--kt-gutter), calc((100vw - var(--kt-container)) / 2))`
2. ロゴ画像に余白が無い
3. 見出しに `margin-left: -0.12em`（「あ」の字形の左の空きを詰める）

**どれか1つを変えると揃わなくなる。** 見出しの書体や最初の文字を変えたら、3の値を調整し直す。2行目の「照」は字形の空きが小さく、約5px左に出る（1行目の「あ」を基準にしたため）。

### 色・余白をまとめて変える

`styles.css` 先頭の `:root` の変数を変える。個別のセクションに色を直接書かないこと。

## 7. SWELLへの移植

1. 各セクション（`<section>` ～ `</section>`）をSWELLのカスタムHTMLブロックに貼る。セクション同士はCSS・JSで依存していないので、1つずつ移せる。
2. `styles.css` を子テーマ（または「追加CSS」）に入れる。
3. `script.js` のうち、ヘッダーとメニュー開閉（01〜03）はSWELLのヘッダー機能と重なるので不要。フェードイン・現在地ナビ・フォーム部分だけ使う。
4. ロゴはSWELLのロゴ設定に `logo-kt.png` を登録する。
5. 画像はメディアライブラリにアップロードし、`src` をアップロード後のURLに書き換える。
6. フォームをSWELL側のフォームに置き換える（上記6）。
7. Google Fonts（Noto Sans JP、Shippori Mincho B1）の読み込みを子テーマに追加する。

## 8. 修正したら確認すること

- [ ] PC（1280px）とスマホ（375px）で、見出し・キャッチが語の途中で改行していないか
- [ ] 横スクロールが出ていないか（ブラウザの開発者ツールで `document.documentElement.scrollWidth` が画面幅と同じか）
- [ ] `h1` が1つだけか
- [ ] すべての画像が表示されるか
- [ ] 電話番号の表示と `tel:` リンクが5か所とも一致しているか
- [ ] **現行サイトに無い文言を足していないか**（足したなら依頼者に申告する）
- [ ] 文字色のコントラスト比が4.5以上か（色を変えた場合）

## 9. やってはいけないこと

| してはいけない | 理由 |
|---|---|
| 文言の書き換え・表記の統一 | 依頼者の指示が「すべて踏襲」 |
| 確認の取れていない情報を足す（実績・数字・インボイス番号など） | 実在の会社について誤った情報を公開することになる |
| アクセント色を増やす・グラデーション・装飾の追加 | 「洗練」「クリーン」の方針から外れる |
| ダークモードを戻す | 依頼者の指示で解除済み |
| 元ロゴ `logo.png` の削除 | 調整前の原本として保管 |
| 事業画像を1MBを超えるまま置く | スマホで表示が遅くなる |
